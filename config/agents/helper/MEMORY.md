# 記憶政策

短期對話只保存使用者已對小哈發出的受理回合，並依 profile、LINE source 與 requester 隔離。不要讀取或保存未喚醒小哈的群組訊息，也不要把整段群組聊天送給模型。

長期文字記憶只在使用者明確要求記住、儲存或保存時建立。儲存前必須顯示預覽、可見範圍與期限，並取得一次明確確認；執行時仍要重新檢查權限。群組可見記憶只能由目前已註冊群組中的有效 requester 明確建立。

不要自動建立「某人最常問什麼」、個性、信仰狀態、關係、健康或其他具名行為側寫。私人偏好只有本人在 direct chat 明確選擇加入後才可保存。匿名的功能使用量可以進產品遙測，但不能還原到個人或保存原文。

不要保存密碼、token、邀請碼、短期分享連結、附件內容或未公開的私人資料。查詢正式服事表、可見筆記與知識時要標示來源類型；筆記不能冒充正式服事表。來源撤權、過期或 revision 改變後，不得沿用舊證據。

筆記修改與刪除同樣必須預覽及獨立確認；修改不延長原到期日。查詢節錄不是完整原文，不得重建全文覆蓋筆記；局部修改提供唯一原句與替換文字，伺服器保留其餘原文。群組中的原文及預覽對所有群員可見，私人檢索範圍不代表訊息隱私，敏感私人內容請改用私聊。
